# 瑞士中国商会2025年度大会圆满举行

<p class="post-meta"><time class="post-date">2026 年 5 月 21 日</time></p>

2026年5月8日，瑞士中国商会（SCEA）2025年度大会在纳沙泰尔的Beau-Rivage Hotel隆重举行，来自商会会员单位的代表、中国驻瑞士大使馆经商处代表及各界嘉宾共聚一堂，共话商会发展，共叙中瑞情谊。

# 

# 年会 | 回顾过去，展望未来

中国驻瑞士大使馆谢国祥公参出席大会并致辞。谢公参在致辞中结合当前国际形势和全球经济发展趋势，深入分析了中瑞经贸合作面临的新机遇与新挑战，全面回顾了两国在经贸往来、双向投资、科技创新等领域取得的积极进展，并展望了中瑞关系未来发展前景。同时，谢公参对商会过去一年来在服务会员、促进交流、推动合作等方面所做的工作给予充分肯定，并围绕中资企业如何提高在瑞合规经营、稳健发展、积极融入当地社会等方面提出了宝贵建议，为在座企业进一步深耕瑞士市场、拓展合作空间指引方向。他表示，希望商会继续发挥桥梁纽带作用，凝聚会员力量，服务在瑞中资企业高质量发展，为推动中瑞经贸合作和民间交流作出更大贡献。

![](/images/news/wechat-h-CflFn99j02aBIkcxmU3A/01.jpg)

瑞士中国商会会长、工商银行苏黎世分行总经理彭晓来先生作2025年度工作报告，回顾了商会在治理运营、会员管理、对外宣传、经贸交流及文体活动等方面取得的工作成果。过去一年，商会持续完善内部治理，积极组织会员活动，促进中瑞文化交流，推动国内多个地方代表团与瑞士政商界开展经贸对接，不断提升服务会员、连接中瑞的平台作用。

![](/images/news/wechat-h-CflFn99j02aBIkcxmU3A/02.png)

![](/images/news/wechat-h-CflFn99j02aBIkcxmU3A/03.png)

财务顾问汪涛先生向会员单位作商会2025年度财务报告。报告显示，商会财务状况稳健，相关收支管理规范有序。

大会还完成了多项重要议程。经与会会员表决，大会一致通过理事会2025年度履职责任豁免事项；选举艾昊先生、曹玉东先生、陆春先生三位新成员加入理事会。同时，大会对肖萍女士、杨威先生、保翔先生三位卸任理事会成员致以诚挚感谢，感谢他们多年来为商会建设与发展所作出的积极贡献。

![](/images/news/wechat-h-CflFn99j02aBIkcxmU3A/04.jpg)

此外，大会正式欢迎比亚迪、贸易发展与标准合作组织（ODCCN）和瑞士中国人社区三家单位加入商会大家庭。新会员的加入将进一步丰富商会会员结构，为商会发展注入新的活力。

![](/images/news/wechat-h-CflFn99j02aBIkcxmU3A/05.jpg)

# 专题演讲|中瑞企业双向投资营商调研报告

大会下半场举行专题演讲环节，圣加仑大学国际管理研究所教授兼中国中心主任克莱特博士与瑞士中心CEO肖振先生联合就最新发布的中企在瑞、瑞企在中营商调研报告作了精彩演讲。

两位嘉宾从学术研究与实践经验出发，围绕中瑞两国企业在对方国度的营商环境、发展机遇与现实挑战进行了深入分析，并与现场嘉宾展开了互动交流。报告内容详实、观点鲜明，为会员企业把握中瑞双向投资与合作趋势提供了富有价值的参考。

![](/images/news/wechat-h-CflFn99j02aBIkcxmU3A/06.jpg)

# 

# 场间休息 | 茶香古韵，共赏东方之美

场间休息期间，聽雨軒（Tingyu Teahouse）创始人董瑞源女士带来中国茶艺展示。一盏清茶，让远在异乡的来宾感受到了熟悉的温暖与宁静，品味东方文化的温润与雅致。

![](/images/news/wechat-h-CflFn99j02aBIkcxmU3A/07.jpg)

来自Frauenfeld的瑞士“文化小大使”、14岁古筝少女杨熹昀（Cécile）也为来宾献上精彩的古筝表演。悠扬的琴声萦绕在纳沙泰尔湖畔，令全场嘉宾沉醉。

![](/images/news/wechat-h-CflFn99j02aBIkcxmU3A/08.jpg)

一茶一筝，展现了中华传统文化的魅力，也为中瑞人文交流留下美好瞬间。

# 

# 摄影比赛作品展 | 光影中的中瑞印象

今年，商会首次举办"光影中的中瑞印象"摄影比赛，面向会员单位征集展现中瑞两国经贸合作、人文交流及自然风光的摄影作品。商会总共收到48幅投稿作品，经初步评选，16幅入围作品在大会会场展出，并开放现场投票。

![](/images/news/wechat-h-CflFn99j02aBIkcxmU3A/09.jpg)

经现场投票，三幅获奖作品最终揭晓。镜头定格中瑞交往的精彩瞬间，拉近了中瑞距离，也展现了会员单位和在瑞中资企业员工眼中的中瑞之美。

![](/images/news/wechat-h-CflFn99j02aBIkcxmU3A/10.png)

# 

# 携手同行，共促中瑞合作

瑞士中国商会将继续秉持开放、专业、务实的宗旨，充分发挥服务会员、凝聚力量、连接中瑞的平台作用，积极促进中瑞经贸合作与人文交流，助力在瑞中资企业合规稳健发展，为中瑞友好合作不断注入新的活力。

期待在下一次活动中与大家再相聚！
